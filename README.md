# ระบบตรวจสอบยอดค้างชำระ (Debt Lookup)

เว็บสำหรับให้ลูกค้ากรอกเบอร์โทรแล้วดูยอดหนี้ที่ต้องชำระ เดือนที่ค้างจ่าย และประวัติบิลที่จ่ายไปแล้ว
พร้อมหน้าผู้ดูแลระบบสำหรับจัดการข้อมูล

## ความสามารถ

**ฝั่งผู้ใช้ (`index.html`)**
- กรอกเบอร์โทร → แสดงชื่อ และยอดค้างชำระรวม
- ถ้าค้างจ่าย แสดงว่าค้างเดือนไหนบ้าง และยอดของแต่ละเดือน
- ตารางประวัติบิลทุกเดือน: ชำระแล้ว (พร้อมวันที่ชำระ) / ค้างชำระ

**ฝั่งผู้ดูแล (`admin.html`)**
- เข้าสู่ระบบด้วยอีเมล/รหัสผ่าน
- สรุปภาพรวม: จำนวนลูกหนี้, ยอดค้างรวม, จำนวนคนที่ค้าง, ยอดรับชำระแล้ว
- ค้นหา/กรองลูกหนี้ (ทั้งหมด / ค้างชำระ / จ่ายครบ)
- เพิ่ม แก้ไข ลบลูกหนี้ (ชื่อ, เบอร์, ยอดต่อเดือน, หมายเหตุ)
- เพิ่มบิลรายเดือน, กด "รับชำระแล้ว" / ยกเลิก, ลบบิล
- ปุ่ม **ออกบิลประจำเดือน** สร้างบิลให้ทุกคนพร้อมกันในคลิกเดียว

## ลองใช้งานทันที (โหมดทดลอง)

ถ้ายังไม่ได้ตั้งค่า Supabase ระบบจะเปิดในโหมดทดลอง มีข้อมูลตัวอย่างให้ และเก็บข้อมูลไว้ในเบราว์เซอร์เครื่องนั้นเท่านั้น

- หน้าผู้ใช้: ลองเบอร์ `0812345678`, `0899999999`, `0861112222`
- หน้าผู้ดูแล: `admin@demo.com` / `admin1234`

> โหมดทดลองไม่เหมาะกับใช้งานจริง เพราะข้อมูลที่แอดมินกรอกจะไม่ไปถึงเครื่องของลูกค้า

## ตั้งค่าใช้งานจริง (Supabase — ฟรี)

1. สมัคร/เข้า [supabase.com](https://supabase.com) → **New project**
2. ไปที่ **SQL Editor** → New query → วางเนื้อหาไฟล์ `supabase/schema.sql` ทั้งหมด → **Run**
3. ไปที่ **Authentication → Users → Add user** สร้างบัญชีแอดมิน (อีเมล + รหัสผ่าน, ติ๊ก Auto Confirm)
4. กลับไปที่ SQL Editor แล้วรันคำสั่งนี้ (เปลี่ยนอีเมล) เพื่อให้บัญชีนั้นเป็นแอดมิน
   ```sql
   insert into public.admins (user_id, email)
   select id, email from auth.users where email = 'you@example.com';
   ```
5. ไปที่ **Project Settings → API** คัดลอก `Project URL` และ `anon public key`
   มาใส่ในไฟล์ `js/config.js`
   ```js
   SUPABASE_URL: "https://xxxx.supabase.co",
   SUPABASE_ANON_KEY: "eyJhbGciOi...",
   ```
   (anon key ใส่ในเว็บได้ ปลอดภัยเพราะตารางถูกล็อกด้วย Row Level Security)

## นำขึ้นเว็บ

**GitHub Pages:** Settings → Pages → Source: `Deploy from a branch` → Branch `main` / `(root)` → Save
รอสักครู่จะได้ลิงก์ `https://<username>.github.io/<repo>/`

**Vercel:** Add New Project → เลือก repo นี้ → Framework Preset: `Other` → Deploy

## ความปลอดภัย

- ลูกค้าทั่วไปอ่านตารางตรง ๆ ไม่ได้ ค้นได้ผ่านฟังก์ชัน `lookup_debt` ทีละเบอร์เท่านั้น
- แก้ไขข้อมูลได้เฉพาะบัญชีที่อยู่ในตาราง `admins`
- ข้อควรรู้: ใครก็ตามที่รู้เบอร์โทร จะเห็นชื่อและยอดหนี้ของเบอร์นั้น
  ถ้าต้องการให้ปลอดภัยขึ้น สามารถเพิ่มการยืนยัน เช่น ให้กรอกเลข 4 ตัวท้ายบัตรประชาชน หรือรหัส PIN ร่วมด้วย

## โครงสร้างไฟล์

```
index.html          หน้าผู้ใช้ (ค้นหาด้วยเบอร์โทร)
admin.html          หน้าผู้ดูแลระบบ
css/style.css       หน้าตาเว็บ
js/config.js        ตั้งค่า Supabase / ชื่อเว็บ
js/api.js           ชั้นจัดการข้อมูล (Supabase หรือโหมดทดลอง)
js/user.js          โค้ดหน้าผู้ใช้
js/admin.js         โค้ดหน้าผู้ดูแล
supabase/schema.sql โครงสร้างฐานข้อมูล + สิทธิ์การเข้าถึง
```
